# ☕ B. G. Patel Tea Shop Management System

## 📌 Project Description

B. G. Patel Tea Shop Management System is a web based application developed using **ASP.NET, C# and SQL Server**.
This system helps to manage products, customers, orders, billing and inventory of the tea shop.

The main purpose of this project is to replace the manual system with a computerized system to improve efficiency and accuracy.

---

## 🎯 Objectives

• Manage product details
• Manage customer records
• Generate bills automatically
• Maintain stock records
• Reduce manual work
• Fast data processing
